LightsOutSoftRes

The all-in-one Soft Reserve and loot distribution addon for Wrath of the Lich King (3.3.5).

LightsOutSoftRes is designed to streamline raid leading by combining SoftRes management, loot announcements, rolling, standings, and Master Loot awarding into a single lightweight addon.

Instead of juggling multiple addons and chat spam, LightsOutSoftRes keeps everything in one place—from the moment the boss dies until the loot is handed out.

Features
Soft Reserve Import
Import SoftRes data from CSV exports.
Automatically organizes reserves by boss and player.
Displays duplicate SoftRes reservations (x2, x3, etc.).
Searchable reserve list.
Smart Loot Detection
Automatically detects loot when a corpse is opened.
Highlights items with SoftRes reservations.
Shows all players who reserved each item.
One-click announcement to raid chat.
Built-in Roll System
Integrated MS/OS rolling.
Configurable roll timer.
Live countdown with raid announcements.
Tracks current standings in real time.
Displays the current leader while rolling.
Advanced SoftRes Logic
Supports multiple SoftRes rolls (x2, x3, x4...).
Automatically ignores extra rolls beyond a player's allowed amount.
Ignores non-SoftRes players on reserved items.
Supports unrestricted open rolls for non-reserved items.
Tie Handling
Detects tied winning rolls automatically.
Allows unlimited rerolls until a winner is determined.
Keeps all other rolls intact during rerolls.
Master Loot Integration
Automatically finds the correct Master Loot candidate.
Confirmation window before awarding loot.
Awards loot directly through Blizzard's Master Loot system.
Marks awarded items to prevent accidental rerolls.
Raid Leader Friendly
Minimal clicks.
Clear interface.
Designed specifically for fast-paced 25-player raids.
Built with Wrath 3.3.5 private servers in mind.

Why LightsOutSoftRes?

The goal of this addon isn't to replace every loot addon.

It's to replace three or four of them.

Import your SoftRes list, kill the boss, announce the loot, run the rolls, resolve ties, and award the item—all without opening multiple windows or relying on separate addons.

Built by raid leaders, for raid leaders.
