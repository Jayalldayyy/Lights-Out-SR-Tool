This is a very simple and clean addon used to import and track Soft reserves from the Softres.it website. 

To use just type /losr import
Paste the CSV info. 
When loot drops that's SR'ed a window will pop up letting you know as well as buttons to announce to raid. 

To see a list of SR's type /losr list

This addon is built for Wow private servers running a 3.3.5 client. (Specifically Chromiecraft but will work on others.)
